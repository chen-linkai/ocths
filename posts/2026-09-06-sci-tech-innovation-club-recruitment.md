## CYH 组

我们目前急需硬件等工程师，如果您满足任意以下条件：

- 掌握 C 语言嵌入式开发。
- 有 STM32F103C8T6 开发经验。
- 有霍尔编码器使用经验。
- 有模型机图传使用经验。
- 有 MLX90640 / GYMCU90640 使用经验。

若满足以下条件更佳：

- 有 Doxygen 文档注释习惯。
- 能够使用 Git 或是拥有活跃的 GitHub 账号。
- 灵活运用 AI 以及其它提高生产力的能力。
